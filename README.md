# ☕ Café 257 — Site Institucional

Site institucional da **Café 257**, uma cafeteria localizada em Cachoeirinha – RS. O projeto foi desenvolvido com o objetivo de ampliar a presença digital do estabelecimento, facilitar o acesso ao cardápio e aproximar a cafeteria de novos clientes.

## 🎯 Objetivo do projeto

Desenvolver uma página web moderna, responsiva e intuitiva para apresentar a cafeteria, divulgar seus produtos e promoções e facilitar o contato com os clientes.

Este projeto também faz parte de uma atividade de extensão acadêmica do curso de Análise e Desenvolvimento de Sistemas (ADS).

## 🚀 Funcionalidades

- Apresentação da cafeteria.
- Cardápio digital com imagens, descrições e preços.
- Filtros de produtos por categoria.
- Seção de promoções.
- Links para redes sociais.
- Acesso ao WhatsApp.
- Localização da cafeteria pelo Google Maps.
- Layout responsivo para diferentes dispositivos.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e responsividade.
- **JavaScript:** funcionalidades e interatividade.
- **Git e GitHub:** versionamento e armazenamento do código.
- **Netlify:** hospedagem gratuita e publicação do site.

## 💻 Como executar o projeto localmente

1. Clone este repositório:

   ```bash
   git clone https://github.com/Kelvinbobsin/site-cafe257.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd site-cafe257
   ```

3. Abra o arquivo `index.html` no navegador.

Também é possível abrir o projeto pelo Visual Studio Code e utilizar a extensão Live Server para visualizar as alterações durante o desenvolvimento.

## 🌐 Hospedagem

O site está hospedado gratuitamente na plataforma Netlify, com publicação integrada ao GitHub.

**Acesse o site:** https://site-cafe257.netlify.app/
